ORCHID data

This is the data site of ORCHID (Open Repository for CALPHAD Hypotheses, Intelligence, and Discovery, orchid-project.org). Every value carries its evidence class (experimental, model, DFT, unspecified; never mixed or averaged), its source paper and DOI, and the table row or short verbatim passage and page it was read from. Release: orchid-literature 2026-10-23 (record store db-v2.1: invariant/general v2.1.19r, text+context fixup-20261022).

Status: Version 1, machine-extracted: values were read from papers by language-model readers constrained to quote their source and checked automatically (quote verification, field-placement rule, printed-page sign checks, DFT and Kim et al. 2017 cross-checks); a hand-checked precision sample is in progress.

Browse without JavaScript

  • Chemical systems — 1818 pages (also Markdown): literature values, invariants, formation enthalpies, calculated phase diagrams.
  • Compounds — 1478 formation-enthalpy pages with DFT comparison.
  • Reporting papers — citation, DOI, systems, number of values.
  • Phase registry — 1241 binary-system pages, 10,496 phases: names, structure (when certain), stability, TDB PHASE/CONSTITUENT statements, example DOIs.
  • Bibliography — 9,568 papers ORCHID knows (read, cited as original sources, behind TDB files and assessed diagrams, discovery leads) with roles, evidence counts and typed relations; per paper and per system.
  • Interactive tools: data explorer, phase diagrams, phase registry, DFT vs experiment.

Folder guide

Folders of the data site
PathContent
literature/Literature records: index.json, systems/<SYS>.json, papers.json, contexts.json, dft_parity.json, full CSV/JSONL dumps; fields in SCHEMA.md.
phase-diagrams/Calculated binary phase diagrams (pycalphad, SGTE binary collection): index.json and sgte/<TDB>.json (phase regions, invariants, grid).
hulls/Binary convex hulls: dft-mp/ (Materials Project), dft-oqmd/ (OQMD), calphad-sgte/ (assessed CALPHAD), one JSON per system.
phases/Phase registry (binary systems): registry.json (compact index) / .csv / .parquet / .jsonld, structure_types.json / .parquet, review_queue.json, CONFLICTS.md, systems/<SYS>.json (full records), pages/<SYS>.html|.md (static pages); fields in SCHEMA.md.
assessed-phase-assemblages/Assessed phase assemblages: one (T, x, P) point deep inside each named phase field of expert-drawn (assessed) binary diagrams (evidence class assessed_phase_diagram): records.jsonl.gz / .csv / .parquet, exclusions, ESPEI ZPF datasets (espei-zpf/, espei-zpf-with-tie-lines/); fields in SCHEMA.md.
espei/ESPEI datasets from the literature, one folder per evidence class (experimental/, model/, invariants/, dft/literature, dft/mp, dft/oqmd), with uncertainties and weights, plus optional tagged phase constraints (derived/invariant-brackets, derived/liquid-stability, assessed/): index.csv, references.bib, VALIDATION.md, UNCERTAINTY_SUMMARY.md, UPSTREAM_CORRECTIONS.md, dft/CALIBRATION.md; fields in SCHEMA.md.
bibliography/Bibliography: every paper ORCHID knows, with Crossref metadata, roles, evidence counts and typed relations: papers.parquet / .csv / .jsonl, edges.parquet / .csv / .jsonl, papers/<key>.json, systems/<SYS>.json, orchid-bibliography.bib / .csl.json, DOI_MISMATCHES.md, pages/ (static pages); fields in SCHEMA.md.
systems/Static pages per chemical system: <SYS>.html, <SYS>.md, <SYS>.csv.
compounds/Static pages per compound (reduced formula): <FORMULA>.html, <FORMULA>.md.
papers/Index of reporting papers.
parquet/Columnar copies of the tables, where present.
zenodo/Zenodo release metadata: one deposition record per citable dataset plus the umbrella record, with file manifests (sizes, SHA-256).
llms.txt, llms-full.txtGuides for language models and agents.

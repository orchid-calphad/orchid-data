ORCHID data

This is the data site of ORCHID (Open Repository for CALPHAD Hypotheses, Intelligence, and Discovery, orchid-project.org). Every value carries its evidence class (experimental, model, DFT, unspecified; never mixed or averaged), its source paper and DOI, and the table row or one verbatim sentence and page it was read from. Release: orchid-literature 2026-10-22 (record store db-v2.1: invariant/general v2.1.19p, text+context fixup-20261022).

Browse without JavaScript

  • Chemical systems — 1813 pages (also Markdown): literature values, invariants, formation enthalpies, calculated phase diagrams.
  • Compounds — 1477 formation-enthalpy pages with DFT comparison.
  • Reporting papers — citation, DOI, systems, number of values.
  • Interactive tools: data explorer, phase diagrams, DFT vs experiment.

Folder guide

Folders of the data site
PathContent
literature/Literature records: index.json, systems/<SYS>.json, papers.json, contexts.json, dft_parity.json, full CSV/JSONL dumps; fields in SCHEMA.md.
phase-diagrams/Calculated binary phase diagrams (pycalphad, SGTE binary collection): index.json and sgte/<TDB>.json (phase regions, invariants, grid).
hulls/Binary convex hulls: dft-mp/ (Materials Project), dft-oqmd/ (OQMD), calphad-sgte/ (assessed CALPHAD), one JSON per system.
systems/Static pages per chemical system: <SYS>.html, <SYS>.md, <SYS>.csv.
compounds/Static pages per compound (reduced formula): <FORMULA>.html, <FORMULA>.md.
papers/Index of reporting papers.
parquet/Columnar copies of the tables, where present.
llms.txt, llms-full.txtGuides for language models and agents.

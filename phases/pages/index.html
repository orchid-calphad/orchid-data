Phase registry (binary systems)

ORCHID phase registry: 10,430 phases in 1241 binary systems, one static page per system. Tier A: the standard phase name encodes one structure; tier B (DFT-supported): a stoichiometric compound matching exactly one on-hull entry in both Materials Project and OQMD; tier C (assessor-stated): the Hallstedt 2025 crystallographic table states one consistent structure for that phase name and system. Everything else is a review candidate.
